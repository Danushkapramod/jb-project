How the System Operates

From API request to instant driver pop-up and WhatsApp message in seconds.

1

Vehicle Owner Registers

Owners register with email & password, contact details, vehicle registration, and select their vehicle type.

2

Field API Call Triggered

External system or farm manager calls POST /api/dispatch with WhatsApp number, date, location & machine type.

3

PickMe-Style Pop-Up

Active owners with matching vehicle type receive an audio chime and pop-up modal to Approve or Deny.

4

Locked & WhatsApp Sent

First owner to approve locks the request. A formatted WhatsApp message is instantly sent to the requester.
